## BugFix: bolt模型闪退 (CXX crash in YOLOv8_det::detect)
- 根因：bolt模型内嵌了完整后处理（DFL解码+anchor解码+sigmoid），输出格式为decoded(8列)而非raw(68列)
- 原始out0: (8400, 8) = [decoded_bbox(4) + sigmoid_class(4)] → generate_proposals算出num_class=8-64=-56，内存越界崩溃
- 修复：修改ncnn param文件，在检测头conv输出层后添加Concat+Reshape+Permute层，产生raw格式out0 (8400, 68) = [DFL_bbox(64) + raw_class(4)]
- 保留所有原始层（.bin文件对齐），原cat_16输出重命名为deadout，新cat_bolt_out产生真正的out0
- modeltype从"m"改为"n"（实际是YOLOv8n架构）
- 文件重命名：yolov8m_bolt → yolov8n_bolt

## Feature: 集成裂纹实例分割模型 (crack segment)
- 新模型来源：crack_segment_ncnn_model/ 目录，Ultralytics YOLOv8n-seg 训练
- 1个类别：crack (裂纹)
- 输入尺寸 640×640，YOLOv8n-seg架构，blob名 in0/out0+out1(3个输出blob)
- ⚠️ 这是第一个seg(实例分割)类型的新模型，继承YOLOv8_seg而非YOLOv8_det

### param修复（比检测模型更复杂）
- 原始模型3个输出：out0(decoded检测+掩码系数) + out1(掩码原型)
- 代码期望3个输出：out0(raw检测) + out1(掩码系数) + out2(掩码原型)
- 修改方案：
  1. 原out0→deadout (cat_18)
  2. 原out1→out2 (silu_147, 掩码原型位置正好对齐)
  3. 新增10层：检测头raw输出(Concat+Reshape+Permute, 65列=64+1)
  4. 新增7层：掩码系数raw输出(Reshape+Permute每stride + Concat, 32列)
- 检测头conv输出blob: 188/207(stride8), 194/213(stride16), 200/219(stride32)
- 掩码系数conv输出blob: 226(stride8), 232(stride16), 238(stride32)
