## BugFix: CMake 版本不匹配
- 报错：[CXX1300] CMake '3.31.5' was not found

- 原因：用户 SDK 中只有 CMake 3.22.1，项目实际只需 cmake_minimum_required 3.10

## BugFix: CMakeLists.txt 变量名语法错误
- 报错：CMake Error at CMakeLists.txt:5 (set): Syntax error
- 原因：set() 的变量名写成了完整 Windows 路径（含冒号），CMake 不允许
- 修复：第 5 行 set(E:\...\opencv-mobile-...) → set(OpenCV_DIR ...)
- 修复：第 8 行 set(E:\...\ncnn-...) → set(ncnn_DIR ...)
- 参考了 CMakeLists copy.txt 中的正确写法
